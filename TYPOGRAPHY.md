# Typography presets

Change one line in `_config.yml`:

```yaml
typography: modern
```

Available presets:

- `modern` — Inter + Space Grotesk. Crisp, contemporary, research-lab feel. **Default.**
- `editorial` — DM Sans + Source Serif 4. More bookish / intellectual; best if you want the site to feel like an online text.
- `technical` — IBM Plex Sans + Mono. Engineer/researcher aesthetic; understated and highly legible.
- `minimal` — Manrope. Cleanest and most neutral; closest to a modern product/research site.

Restart the local Jekyll server after changing the value. No CSS edits are needed.
